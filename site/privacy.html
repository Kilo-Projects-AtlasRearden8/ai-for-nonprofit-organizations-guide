Privacy-safe workflow

This guide is built around one promise: your data stays on your computer.

The three data zones

ZoneWhat goes inWhere it runs
PublicEvent flyers, public schedulesAnywhere
InternalBudgets, volunteer lists, donor namesLocal model only
SecretBank details, passwords, personal addressesNever in AI

Rules for every task

  • Grant letters: budgets are internal. Use a local model.
  • Donor thank-yous: names and amounts are internal. Use a local model.
  • Event flyers: public by nature. Safe for hosted models — but no personal phone numbers.
  • Volunteer schedules: names and availability are internal. Use a local model.

How to use a hosted model safely

  1. Strip all names, amounts, phone numbers, and addresses.
  2. Replace them with placeholders: [ORGANIZATION], [AMOUNT], [VOLUNTEER A].
  3. Ask the model to work on structure only.
  4. Fill in real data yourself, on your computer.

Local model setup

ollama pull llama3.2
ollama run llama3.2

Checklist before you send

  • No names or amounts sent to a hosted service.
  • No API keys or secrets in any file.
  • Sensitive drafts saved only on your computer.
  • A real human read the final document.
