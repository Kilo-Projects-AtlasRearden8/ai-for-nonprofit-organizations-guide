Prompt library

Copy-paste starting points. Fill in the [BRACKETS] with your own facts.

How to use a prompt well

  1. Give facts first — AI cannot guess what you have not told it.
  2. Say "use only these facts" — stops the AI from inventing things.
  3. Ask for [INSERT] markers when a fact is missing.
  4. Set the tone — warm, formal, plain, confident.
  5. Check everything — AI drafts are drafts.

Grant letters

Write a grant proposal. Use only these facts.

Organization: [name]
Mission: [mission]
Funder priority: [paste funder priority]
Project: [name and summary]
Problem: [what problem + example]
Goal: [what you will achieve]
Budget: [total amount]
Timeline: [start, end, reporting date]

Write sections: Executive Summary, Problem Statement, Project Description,
Goals and Evaluation, Budget Overview (table), Timeline.

Do not invent facts, numbers, or programs. If a fact is missing, write "[INSERT]".

Donor thank-you notes

Write a warm, sincere thank-you note. Use only these facts.

Donor: [name]
Gift: $[amount] on [date]
Impact: [one specific thing the gift provides]
Tone: [warm / formal / casual]
Length: 100-150 words
Do not invent facts or relationships.

Event flyers

Write flyer copy. Use only these facts.

Event: [name]
Audience: [who it is for]
Date: [date]
Time: [time]
Location: [address or link]
What happens: [list]
How to register: [instructions]
Contact: [name and email]

Write: Headline, Sub-headline, Description (50-80 words), Key details, Call to action.

Do not invent facts, dates, times, or locations.

Volunteer schedules

Build a volunteer schedule. Do not invent volunteers.

Event: [name]
Shifts needed: [shift | start | end | volunteers needed]
Volunteers and availability: [name | available shifts]

Rules:
- Each shift must have the listed number of volunteers.
- Do not schedule a volunteer outside their availability.
- Spread shifts fairly.

Output: Date | Shift | Time | Volunteers assigned. List unfilled shifts.

General helpers

  • Simplify: "Rewrite this at a 6th-grade reading level. Keep every fact."
  • Tone shift: "Rewrite this paragraph in a [warm / formal / urgent / casual] tone."
  • Grammar: "Fix spelling and grammar. Do not change the meaning."
  • Summarize: "Summarize this document in 3 bullets."
